What we could not see

  • We read each app's code. We did not run the apps, so we cannot say which switched-off features drivers actually see.
  • EverDriven's iPhone release notes mention live chat, but the Android code has chat wording and no working chat screen. This is still open.
  • EverDriven's automatic arrival at a stop sits behind a setting we cannot see. Only the manual "I Have Arrived" button is confirmed.
  • Zum markets its drivers as hourly employees, yet the Android app also contains weekly payouts and 1099 tax forms used for contractors. Who sees those screens is unknown.
  • HopSkipDrive's offline behaviour is not described anywhere we looked.
  • No pay or earnings screen was found in EverDriven's app. Drivers are paid by their transport provider.
  • Ratings come from store listings read in September and October 2026.
