What we could not see

  • We read each app's code. We did not run either app, sign in, or see any real content or records.
  • The two tools do different jobs. Beacon's is for news and engagement; STA's is for HR records. Many "not found" answers reflect that, not a gap in one product.
  • Beacon's admin portal, and the Workday, PerkSpot and chatbot content it links to, sit outside the app. We could not see them.
  • A store review says drivers open the driver app from MyBeacon. The code has no driver tools, so this may be a link in the Hub. Not confirmed.
  • Our analysis says MyBeacon is used by drivers, monitors and office staff. No role data in the code proves it.
  • For STA we loaded the public sign-in page once. Server logic, permissions and the UKG, WorkBright and DriverHub syncs are not visible.
  • "DriverHub" in STA's app is a source of job applicants. It is not First Student's DriverHub. What it is exactly is unknown.
  • We do not know whether drivers use STA's app themselves, or only office and HR staff.
  • We do not know which states' exams STA uses beyond the examples in the code.
  • The MyBeacon rating comes from the iPhone store listing read in October 2026. STA's tool is a web app with no store listing.
