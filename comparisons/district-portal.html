What four competitors give schools and districts

District transport teams use these web portals to request rides, follow them, cancel them, pay for them and report on them. School staff use them to see who is arriving. EverDriven, HopSkipDrive and Zum serve alternative transport. Beacon Mobility runs yellow buses. Each strip below is one portal. Every square is one thing a district can do.

What we could not see

  • We read each portal's code from its public sign-in page. We did not sign in, so we cannot say which screens a given district has switched on.
  • Zum's portal holds tools for districts, vendors, Zum's own operations and finance in one app. Which of them district users see is set by roles we cannot see.
  • EverDriven's invoicing page loads only after sign-in, so its contents are unknown.
  • EverDriven markets its district hub as TripCentral. The portal code calls it the District Portal or Ride Manager.
  • HopSkipDrive's SIS import and some other features may be switched off for some accounts.
  • Zum's portal includes tools for AI agents. What they do is not visible.
  • Beacon's portal loads its 16 feature screens only after sign-in. We saw their names and the permissions that guard them, not what they show. Where the help guides describe a screen, we used them.
  • No billing or invoice screen appears in Beacon's portal code or help guides. How Beacon bills districts is unknown.
  • Beacon's portal has an ETA screen. What it shows and how the times are worked out is not visible.
  • Beacon's help guides date from July 2025 to June 2026, so some details may have changed.
