What six parent apps give families

Three apps come from alternative transport: HopSkipDrive, EverDriven and Zum. Three serve yellow bus routes: Beacon Mobility's BC Family, Here Comes the Bus, and ByteCurve's SafeStop, which shares its code with BusZone, Summit's parent app. Each strip below is one app. Every square is one thing a parent can do, grouped by area and coloured by what we found.

What we could not see

  • We read each app's code. We did not run the apps, so we cannot say which switched-off features parents actually see.
  • EverDriven has two cancellation rules. The parent app blocks cancelling within an hour of the trip. The district portal warns of a charge within 2 hours.
  • Zum's Android app declares 14 languages, but the copy we analysed held English text only. The help centre lists 10 languages.
  • Zum's parent app still carries code for carpools, babysitting and promo codes from its earlier consumer days. No parent screen uses it.
  • Zum ships driver vetting badges in the app, such as criminal record and DMV checks. We cannot tell which drivers carry them today.
  • HopSkipDrive carpools sit behind a switch we cannot see.
  • Many Here Comes the Bus features, such as adding children and Skip Ride, are switched on by each district. We cannot see which ones Omaha uses on STA routes.
  • The Here Comes the Bus Android build calls itself a beta of a rebuilt app, with activity trips switched off. The iPhone app may differ.
  • SafeStop is one white-label app shared by SafeStop, BusAlert, BusZone and Zonar MyView. We read the shared features. Each brand's settings come from the server, so BusZone may not show all of them.
  • BusZone dropped text alerts for card scans in 2024, but the shared code still offers them.
  • Beacon's help centre promises boarding and drop-off alerts, but the BC Family code lists none. The help centre also says the bus shows only inside your zone, while the code points to a live map. Both are open.
  • For all six we read the Android app only. iPhone versions may differ.
  • None of the six states a formal accessibility standard for its parent app.
  • Ratings come from iPhone store listings read in September and October 2026. Android ratings for the three yellow bus apps were not readable. The Here Comes the Bus rating covers all districts.
