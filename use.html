Quick start

First time only. Run these in the VS Code terminal, from the folder that contains CLAUDE.md.

  1. Put the folder under git and enable the hooks 
    git init -b main
git config core.hooksPath .githooks
git add . && git commit -m "FirstAlt Product Council v3.7"
  2. Nothing to register or installIDs carry a date and a random suffix. Diagrams render with Python's standard library.
  3. Start work on your own branch 
    bash scripts/start_work.sh first-context
  4. Open Claude Code and check healthThe session briefing appears on its own. Then run /check.
  5. Add contextDrop files into context/00-sources/ and run /ingest <folder>, or /ingest <url> for a web page.
  6. See a diagram page/diagram demo renders an example of every type and a three-flow feature page into diagrams/demo/.

Modes

/council reads the mode from your request and names it in its first line, for example Mode: solve. Tier 2: a symptom of unknown size. Override with --mode.

The five modes. A mode changes only what it needs before starting, which panels it leans on, and the shape of the round.
ModeYour request sounds likeNeeds before startingDefault panelsRound shape
brainstorm"Ideas for X". No solution yet, no confirmed problemWhich user, which outcome, which part of the journey. A vague theme is refusedproduct, board, industry, competitors, usersAt most 3 ideas per panel, each tied to an evidenced problem. Shortlist 3, cross-examine only those
improve"The Y flow is clunky". A named existing featureThe feature as it works today, from context or from you. Never imaginedusers, product, competitors, techUser Panel reads today's flow first. Draws today against the pick with /diagram compare
solveA complaint or symptom of unknown sizeNothingboard, industry, users, techProblem half first (real, who, how often, root cause), a checkpoint on the problem statement, then solutions
validate"Should we build X". A proposal, PRD or designThe proposal, with every assumption tagged V, I or Uboard, product, tech, users, competitorsPanels attack the proposal and never rewrite it
radar"What are we missing"Nothingproblem-radar aloneRanked problems with evidence, no verdict. Saved to reports/problems/

At Tier 2 only the one or two most relevant default panels run. --panels replaces the defaults.

Flags

For /council unless the row says otherwise.

Every flag worth knowing.
FlagWhat it doesExample
--modeOverride the inferred mode: brainstorm, improve, solve, validate or radar--mode validate
--panelsChoose panels: board, product, tech, industry, competitors, users. One panel runs at Tier 1--panels board,users
--onlyOne voice inside a panel--panels board --only premortem
--dimensionBoard only. One lens: problem, risk, clarity, scope or strategy--panels board --dimension risk
--iterateRe-run against a revised idea, carrying the previous findings--iterate sessions/<file>.md
--segmentCompetitor segment: alt, bus or both--segment alt
--thoroughOne challenge round at Tier 2. Cheaper than --deep--thorough
--deepTier 3: 3 to 6 panels, full personas, up to two challenge rounds--deep
--fullFull persona files instead of compact cards, without going to Tier 3--panels tech --full
--diagram, --no-diagramForce or skip the diagram step--no-diagram
--fastSkip both question rounds and decide on the stated defaults--fast
--analysisContinue from an analysis document: its answers, data and open questions are the starting point, and it is updated as you go--analysis driver-change-notice
--dry-run, --limit/ingest on a folder: the plan only, or the first n files/ingest context/00-sources/transcripts --dry-run

What to say mid-session

You steer the council in plain words at any point.

SayWhat happens
"Go deeper"Moves up one cost tier and reuses the work already done
"Go"Answers a question round with the defaults it offered
"Decide now"Skips any remaining question round and decides on the stated defaults
"About 40 a week"A figure for the data request. The reply says whether it confirmed, changed or flipped the pick
"Continue the driver change analysis"Same as --analysis: picks up that document and builds on it
"Premortem, what if districts refuse?"That persona answers in character, then the session continues
"Add the user panel, drivers and providers only"Brings in a panel mid-session with the personas you name
"New fact: providers approve within 2 days"Used straight away, then you are asked once: this analysis only, or a curated key fact, rule or background
"Focus on adoption, not pricing"The Product Lead redirects the discussion
"No, that was only a proposal"Any correction fixes the output, and a lesson is captured
"A" or "B" when asked about a conflictYour choice goes to the decisions ledger, so it is never asked again
"Draw it" or "show me the flows"Draws every flow the pick touches on one page, even where the council would have skipped it
"Compare with today"Adds today against the pick to the page, with every change colored and listed
"No diagram"Skips the diagram step for this session
"Run the premortem on this"Same as --panels board --only premortem
